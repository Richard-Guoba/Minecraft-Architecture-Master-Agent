## 本集解决的问题

本集主要介绍高版本建筑工具包，其中可迁移到 Agent 的不是模组清单，而是三个工作方法：建筑群要在更远的环境尺度中规划；材料选择可以组织成相邻颜色的渐变带；形体评估应加入远距离、透视压缩较小的观察视角。

## 字幕摘要

- 更长的可见距离能让建筑群与周边环境同时被观察，改变只围绕近处、单体建筑工作的逻辑（约 51–94 秒）。
- 调色板可以从目标颜色检索相近颜色方块，并把不同棕色方块排成渐变带（约 130–170 秒）。
- 近距离观察会强化近大远小；退远后使用中焦式缩放，更容易呈现建筑原本的体块关系（约 202–250 秒）。
- 作者再次区分施工用光影：施工阶段重视合适的白平衡、色调、兼容性和流畅性，而不是只追求梦幻展示效果（约 338–362 秒）。

## 可执行流程

1. 单体体块确定后，增加一个远景上下文检查，观察建筑与相邻建筑、道路和地形的整体关系。
2. 材料方案不只列离散方块；为主要色系建立从暗到亮或从冷到暖的有序 `palette_ramp`。
3. 在墙面或屋顶的大区域内，以结构区域为边界使用渐变，不把颜色随机撒满所有表面。
4. 至少从近距离主要观景面和远距离压缩透视视角各检查一次形体。
5. 施工评估使用中性、稳定的观察条件；展示性光影不能作为唯一的结构判断依据。

## 给 Agent 的转化

- `context_horizon`：单体之外需要纳入构图的环境距离和对象集合。
- `palette_ramp`：按颜色或明度邻近关系排序的材料角色，不等于随机材料池。
- `evaluation_view: distant_compressed`：用于复核体块比例和建筑群关系的远距离视角。
- `evaluation_view: primary_close`：用于复核入口、立面层次和细节的近距离主视角。
- 同一候选必须在两种视角下保持主体可读；展示光影只影响呈现，不应掩盖形体问题。

## 尚未证明

- 视频没有给出适用于所有建筑群的视距数值。
- 棕色渐变只是演示，不应锁定具体材料、渐变长度或颜色数量。
- “中焦”是作者对观察效果的描述，本集没有给出可移植的相机焦距参数。
- 工具包版本、前置模组和下载配置不进入建筑知识或数据包运行时。
