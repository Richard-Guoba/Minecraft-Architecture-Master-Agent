## 本集解决的问题

体块数量增加并不会自动提高质量。如果多个体块尺度相近、平行摆放且细节等量，它们会互相争夺注意力。本集把“主次”转成主体最大、辅助体块从属、焦点不分散的组织关系。

## 可执行流程

1. 为所有体块标注 `primary`、`secondary` 或 `connector`。
2. 主体取得最大的高度、体积或最显著位置，至少占据一种优势。
3. 次体与主体产生依附关系，不同时争夺全部优势。
4. 连接体负责消除断裂，不成为第三个视觉中心。
5. 从主视角做剪影检查：观察者是否能在一秒内指出主体。
6. 如果不能，降低次体高度、缩小体积、后退位置或简化细节。

## 给 Agent 的转化

在体块规划 JSON 中强制指定唯一 `primary_volume_id`。评价器检查最大体积、最高点和主视角屏幕面积是否全部被不同体块占有；若优势过度分散，返回“主次不足”，让 LLM 选择缩小、后退或合并次体。
