## 本集解决的问题

本集针对只会用楼梯逐层铺坡面的局限：固定楼梯形态在大型或渐变坡度屋顶上会形成明显横纹、锯齿，并占用本可用于局部变化的位置。课程用整砖主坡面扩展颜色和曲线选择，再通过有控制的包边、局部雕刻和顶部构件建立层次，同时要求繁复区域与简洁区域形成对比，并允许现代需求直接使用平顶或露台收口。

## 字幕摘要

- 基础人字坡顶、不同坡度和简单包边只是起点；课程目标是突破把所有屋顶都套入同一楼梯坡面模式的倾向（约 0–91 秒）。
- 楼梯在小尺度 45 度坡面上可以合适，但大型、渐变坡度屋顶会显出重复横纹和折线；用整砖建立主坡面可以减少这种限制，并腾出局部细化位置（约 91–228 秒）。
- 整砖提供比楼梯和台阶更宽的颜色库存；建筑尺度足够大、观察距离较远时，可提高整体色块权重，但小尺度或近景仍需检查矿物、功能方块等强纹理是否突兀（约 262–410 秒）。
- 包边不必固定使用楼梯；整砖、墙、栅栏及允许的小构件可以组合屋脊与边线，但整体高度、连接和比例仍需控制（约 427–589 秒）。
- 建筑群或完整屋面不必处处繁复；保留干净屋面，与局部雕花和重点构件形成有繁有简的对比，避免细节铺满全表面（约 589–675 秒）。
- 曲面屋顶可以从整砖主坡面开始，通过局部挖补，再用楼梯或台阶过渡；需要反复检查和调整，而不是把一次示例固化为模板（约 675–779 秒）。
- 后半段展示多种屋顶顶部和棚顶构件，反复强调按视觉形状而非方块原用途理解材料；字幕中的“乱堆”是作者的自由雕刻表达，不能直接转成无约束随机生成（约 780–1,200 秒）。
- 对明确的现代平顶或露台需求，可以用平面和女儿墙结束，不应默认强加坡屋顶（约 1,200–1,334 秒）。

## 可执行流程

1. 用 `roof_surface_primitive` 选择主坡面表达：固定坡度和小尺度可保留楼梯；大型或逐段变化的坡面先检查楼梯层列是否形成强横纹、锯齿或比例错位。
2. 若楼梯表达失败，改用整砖生成主要 `roof_surface`，把楼梯、台阶或墙限定为边缘、过渡和局部细化构件，不要求每层连续铺满同一种形态。
3. 扩展 `roof_palette` 时执行尺度检查：远景先判断整体颜色和渐变，近景再检查单块纹理、接缝及功能方块外观；强纹理只在足够尺度或明确点缀角色下使用。
4. 建立 `roof_detail_mask`：把包边、雕花、顶部构件和表面变化集中到少量焦点或边线，同时保留干净坡面；建筑群中让繁复屋顶与简洁屋顶形成主次。
5. 曲面优化沿用 `roof_profile_phases`：在整砖基础上进行有边界的挖补和填充，再用允许的部分方块过渡；每轮回到整体轮廓和比例检查，而不是无约束随机雕刻。
6. 顶部或棚顶附属构件必须连接屋面或可读支撑；过高时降低、缩短或补充柱和斜撑，不能让细节成为漂浮物。
7. 当 brief 明确要求现代平顶或露台时选择 `flat_roof_with_parapet`，不强制添加坡顶；排水、防水和现实工程细节保持未解决，不由字幕推断。

## 给 Agent 的转化

- `roof_surface_primitive`：按尺度、坡度节奏和目标纹理在整砖主面与楼梯课程之间选择。
- `large_roof_full_block_surface`：整砖用于大型或渐变坡面的主体，部分方块用于过渡和边缘。
- `roof_detail_mask` / `detail_density_contrast`：限定细节作用域，让繁复焦点与干净屋面形成层级。
- `roof_profile_phases`：通过有边界的挖补、填充和部分方块过渡迭代曲线。
- `flat_roof_with_parapet`：现代平顶或露台是有效屋顶分支，不被人字坡顶模板覆盖。
- `evaluation_view`：远景判断色块、横纹和轮廓，近景判断强纹理、接缝与构件连接。
