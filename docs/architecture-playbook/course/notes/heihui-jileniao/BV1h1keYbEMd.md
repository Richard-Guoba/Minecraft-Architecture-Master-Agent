## 本集解决的问题

本集把基础坡屋顶扩展为可组合、可变形的屋面系统：屋脊朝向应服从最终高度与轮廓，边框和屋脊也要进入总高度预算；L、T、十字与次级屋顶需要明确连接和接缝清理；曲面轮廓用可调整的坡度阶段表达；偶数跨度不必强行套用唯一的对称尖顶收口。

## 字幕摘要

- 同一基础体块沿不同轴向起坡会产生不同的屋顶高度和侧面观感；课程反对把一种方向机械套给所有建筑，同时明确保留有意为之的例外（约 6–78 秒）。
- 包边可以连续、抬高或局部改变；屋脊和叠加雕饰会继续增加最终高度，因此核心坡面需要为这些构件预留高度（约 78–221 秒）。
- 大坡面可用较缓的次级屋顶、山面处理、L/T/十字相交屋面、天窗或老虎窗切分；相交处应填合连接并删除重复部分（约 277–488 秒）。
- 曲面与穹顶通过坡度逐段变缓、变陡或反向形成；楼梯等构件在不同尺度下效果不同，示例不是固定模板（约 575–830 秒）。
- 平屋顶可以用女儿墙结束；偶数跨度可通过偏移屋脊、改变两侧坡度节奏、顶部直接收合或加入次级结构完成，不必死守单一对称尖顶（约 832–970 秒）。
- 结尾案例强调观察既有建筑的屋顶手法并持续积累；局部高对比材料可能近看成立、远看却增加过强纹理感，应同时检查近景和远景（约 970–1,271 秒）。

## 可执行流程

1. 建立 `roof_axis_candidate`：对体块允许的主轴分别生成屋脊朝向候选，比较最终高度、山面比例和整体轮廓，不用固定“长边”或“短边”规则代替比较。
2. 建立 `roof_component_budget`：核心坡面、包边、屋脊和叠加雕饰共同占用最终高度；附加构件使轮廓过高时，先降低核心坡面或减少叠层。
3. 用 `compound_roof_graph` 把主屋顶、次级屋顶、L/T/十字分支、天窗和老虎窗绑定到对应体块或开口，不生成没有下部依据的随机屋顶碎片。
4. 每次组合后执行 `roof_seam_repair`：填合交接区域，删除重叠构件，检查包边连续性，并让次级屋脊正确终止于主屋面。
5. 用 `roof_profile_phases` 表达逐段坡度变化；根据尺度选择整块、楼梯、台阶或允许的细构件，不把视频中的某条曲线固化成全局模板。
6. 对偶数跨度执行 `even_span_closure`：从偏移屋脊、改变坡度节奏、短平顶或顶部次级结构中选择一个有意图的收口，再检查左右轮廓和承托关系。
7. 在 `primary_close` 检查接缝、包边与构件，在 `distant_compressed` 检查总高、轮廓和纹理密度；远景出现噪声时减少或重组细小高对比材料。

## 给 Agent 的转化

- `roof_axis_candidate`：屋脊朝向由候选的高度与轮廓比较决定，不由单一边长规则决定。
- `roof_component_budget`：把包边、屋脊和顶部雕饰纳入总高预算。
- `compound_roof_graph` / `roof_seam_repair`：组合屋面必须对应下部体块或开口，并清理连接处重复与断缝。
- `roof_profile_phases`：用可解释的坡度阶段表达平缓、陡峭和曲线变化，并按尺度选择构件。
- `even_span_closure`：偶数跨度允许受控不对称或短平顶收口，但必须重新验证轮廓与承托。
- `evaluation_view`：近景判断连接细节，远景判断屋顶总形与材质纹理密度。
