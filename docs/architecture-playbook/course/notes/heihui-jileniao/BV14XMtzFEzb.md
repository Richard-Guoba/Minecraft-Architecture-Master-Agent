## 本集解决的问题

配色不是逐块寻找“好看的方块”，而是建立整体色彩层级，并让颜色、纹理、可用方块形态、建筑尺度和周围背景协同。作者给出的是可调整的经验和参考，不是固定答案；具体历史风格仍需使用对应建筑资料约束。

## 字幕摘要

- 通体使用相近浅黄色会缺少天然层次；适当区分屋顶、框架和填充墙能提高可读性（约 15–40 秒）。
- 深色具有更强的视觉引导作用。让柱梁框架比墙面填充更深，可突出线条和结构次序；反向配置可能让层级混乱（约 79–124 秒）。
- 作者建议主要色调控制在约三四种以内，小面积点缀另计；这是一条经验起点，不是硬性上限（约 127–179 秒）。
- 建筑与道路或背景需要适当区分；灰色道路旁再用灰白墙面，房屋容易与背景糊成一块（约 302–371 秒）。
- 小比例屋顶需要楼梯、台阶、墙等小形态才能形成精细曲线，因此应先确认材料的形态库存，再选择墙面材质（约 390–464 秒）。
- 材料的视觉构造应与形体相容：字幕以圆形石塔和方整木架为例，并明确说明这只是参考而非固定标准（约 466–559 秒）。
- 少量异色如果只出现一次会突兀；在其他构件中适当重复、呼应，能把多个颜色组织成整体（约 668–773 秒）。
- 大尺度、远距离时单块纹理影响减弱，可扩大整砖材料的选择；小尺度则受楼梯、台阶等形态精度限制（约 797–818 秒及 917–974 秒）。
- 建筑群要共同配色，同时可以用一个高明度或高饱和度焦点打破大面积灰白，但要通过周围细节点缀建立联系（约 974–1015 秒）。

## 可执行流程

1. 从屋顶、框架、墙面和基座定义 `palette_role`，先选择少量主色，再单列点缀色。
2. 建立 `value_hierarchy`：检查框架线是否能从填充面中读出，入口和主体焦点是否拥有明确的对比优先级。
3. 对每个候选材料记录 `shape_inventory`，确认整块、楼梯、台阶、墙等形态能否满足目标尺度和曲线精度。
4. 执行 `background_separation_check`，比较建筑与道路、地面、邻近建筑的明度、色相和饱和度。
5. 对突出的点缀色建立 `accent_echo`：在至少一个从属区域以更小面积重复同源颜色，而非散布无关随机色。
6. 在近景检查纹理和形态接缝，在远景检查主要色块、框架和建筑群焦点。
7. 若目标风格具有历史配色约束，记录参考来源；没有证据时不把个人组合伪装成风格定制。

## 给 Agent 的转化

- `palette_role`：`roof | frame | infill | base | accent | landscape`。
- `value_hierarchy`：各角色之间预期的明度与视觉优先级关系。
- `shape_inventory`：一个材料家族可用的整块、楼梯、台阶、墙和其他形态。
- `background_separation_check`：主体与地面、道路及邻近体块的可分辨性检查。
- `accent_echo`：在从属区域重复焦点色，使其成为有意的色彩关系。
- `palette_scope`：`building | building_group | landscape_context`。

## 候选建筑规则

### 用明度层级显示结构次序

- 适用：框架—填充墙、屋顶—墙面和基座—主体组合。
- 动作：为承担构图线的框架设置清晰但协调的明度差，并从远景确认其连续可读。
- 失败：填充面抢过框架；所有角色明度相近而糊成一块；高对比线条无结构目的。

### 让材料形态库存匹配建筑尺度

- 适用：小比例屋顶、曲线、檐口和雕花。
- 动作：在锁定颜色前确认候选材料是否有目标几何需要的楼梯、台阶或墙体形态；不足时换材料、放大尺度或简化曲线。
- 失败：颜色合适但只有整块，导致小尺度轮廓锯齿或过厚。

### 用呼应组织点缀色

- 适用：单个建筑或建筑群中的高明度、高饱和度和异色色块。
- 动作：保留一个主要焦点，在较小从属构件中重复相近颜色，并检查面积主次。
- 失败：异色只出现一次而突兀；为了呼应平均撒满全局，反而失去焦点。

### 让主体从地面和邻近背景中分离

- 适用：道路、广场或同色建筑群旁的房屋。
- 动作：至少在明度、色相、饱和度或轮廓边界中建立一种稳定差异。
- 失败：墙面与道路或背景共享近似色值，远景中主体边界消失。

## 尚未证明

- “三四种主色”是作者建议，不是所有建筑的硬限制，也不包含小面积点缀。
- 本集没有给出颜色差、点缀面积或背景分离度的数值阈值。
- 石塔与木架的形体关系是示例性建议，不应转换为不可违反的材料规则。
- 中式等具有历史约束的配色需要额外资料；本集没有提供可直接编码的完整制度。
- 具体方块名称可能受 ASR 影响；规则依赖可观察的颜色、纹理和形态库存。
