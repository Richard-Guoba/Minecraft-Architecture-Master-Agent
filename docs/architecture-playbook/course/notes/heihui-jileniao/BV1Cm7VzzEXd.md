## 字幕摘要

- 选址同时需要近、中、远景和可穿透视廊，在包围感与透气感之间平衡（约 20–60 秒）。
- 大尺度远景主要读取颜色和覆盖面，微纹理退居其次；连续垂落植被打破悬崖横向条带（约 90–331 秒）。
- 先铺粗细不同的主次道路，再按道路分出的地块形状与大小放建筑、花田或水体（约 390–510 秒及 540–631 秒）。
- 水体应有来源、流向和出口，花田与小景保持局部密集而非全部铺满（约 540–631 秒）。

## 可执行流程

1. 先验证景观层次和视廊，再建立远景色块与悬崖连续线。
2. 布置主次道路，让路线自然产生可用地块。
3. 按地块角色填入建筑、种植或有来源的水体并限制重复密度。

## 尚未证明

- 字幕没有给出视廊角度、道路宽度或地块面积阈值。
- Axiom、画笔、复制旋转和材质包不是便携生成依赖。
- 大尺度“忽略材质性质”仅限远景视觉判断，不能绕过方块兼容性。
