## 本集解决的问题

墙面质量并不等于装饰方块数量。本集把墙面拆成框架、墙芯、开口、进深、分区和细节六层，并说明大墙面应先被分割，重复墙间应主动变化。

## 可执行流程

1. 沿结构边界放置柱和横梁，得到墙间框架。
2. 把墙芯填入框架内部，不与外框完全共面。
3. 根据室内功能放置门窗开口。
4. 通过外框前移或墙芯后退建立真实阴影层。
5. 对大墙面先进行竖向与横向分区，再处理每个小区域。
6. 让相邻墙间共享语言，但改变至少一种：宽度、高度、开口、支撑或细节密度。
7. 最后才添加窗台、绿植和小构件，并检查是否喧宾夺主。

## 给 Agent 的转化

墙面规划器先输出 `bay_grid`，每个墙间包含框架深度、墙芯深度、开口和细节预算。固定算法填充方块；LLM 决定哪些墙间重复、哪些发生变化。评价器分别检查共面率、连续空白面积和重复签名，而不是只统计方块种类。
