## 本集解决的问题

单个长方体只能给出占地，不能自然产生构图。作者把复杂住宅还原成少量长方体之间的高度、朝向、交叠和遮挡关系，再从这些关系抽取结构框架。

## 可执行流程

1. 用一个长方体表示最低限度的可用空间。
2. 加入一个更高的主体体块，建立主要轮廓。
3. 加入一个更低或更小的辅助体块，避免所有体块等权。
4. 调整体块朝向和交叠深度，使轮廓至少出现一个凹入和一个伸出。
5. 从正面及主要观景角检查连续空白面。
6. 用前后层叠或相交体块切断过大的空白区域。
7. 体块关系稳定后，再沿边角抽取柱、梁和屋顶承接线。

## 给 Agent 的转化

LLM 不直接输出每块方块，而是先输出三个参数化体块：主体、次体、连接体。固定算法负责把体块离散成方块；LLM 负责选择尺寸关系、交叠方式和主视角。生成后先渲染灰模，检查轮廓与空白面，再进入框架阶段。
