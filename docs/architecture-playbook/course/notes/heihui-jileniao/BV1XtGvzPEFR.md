## 本集解决的问题

本集把墙面装饰拆成可组合的微观构件，并延续上一集“先有墙面层级和结构，再放细节”的次序。课程用窗、窗台、柱和外挂构件说明：装饰可以删减、替换和组合，但必须与墙体、柱梁、比例和视觉重量形成关系；空间受限时，也可以在一格进深内使用部分方块建立有限浮雕，而不是强制继续内退。

## 字幕摘要

- 基础墙面可以先增加边框，再将墙芯内退一格，为后续装饰提供画布；墙面越大可以容纳更多层次，但字幕没有规定层数（约 22–104 秒）。
- 内退后要补足柱与横梁的可读支撑。细构件可通过不同朝向、打开状态和连接状态形成弧线或托撑；较大尺度可以用整砖和半砖获得更平滑的轮廓（约 105–183 秒）。
- 墙脚可以容纳座椅、植物、护栏或隐藏照明等从属用途，但这些示例不是必须项，也不构成全局细节清单（约 183–276 秒）。
- 窗台可以拆成上部遮雨构件、中部开口和下部置物台；上下部件都可按用途删减。锁链表达拉力、底部或侧部构件表达支撑，整体仍需保持风格一致（约 276–411 秒）。
- 圆窗、方窗和材料变例来自同一构件组合思路；孤立的新材料若没有与墙体和柱体共同构建，会显得突兀（约 413–513 秒）。
- 深色、视觉较重的材料适合框架和承托，浅色、视觉较轻的材料适合填充面；冷色体系可以用受控暖色点缀调和，但不能由此推导固定配色表（约 513–565 秒）。
- 柱子可分为柱基、柱身和柱头，用部分方块形成较细的分段。小比例柱若被大楼梯或整块雕花包围，装饰会压过柱身；此时应删减装饰或放大柱与开间（约 565–754 秒）。
- 向外延伸的横梁或上层体量需要相应增加承托；课程反复强调按视觉受力直觉和既有风格组织细节（约 762–827 秒）。
- 当空间或材料限制不允许墙芯内退时，可以在一格范围内用墙、活板门等部分方块建立有限凹凸；外挂构件的长度和位置还应服从建筑尺度及墙柱交接位置（约 885–1,023 秒）。
- 大墙面才需要进一步分区；一格小面没有必要强行切分。课程还用木纹横纵方向作为装饰变量，补强了按视觉属性而非名称分配材料的做法（约 1,043–1,137 秒）。

## 可执行流程

1. 复用 `facade_depth_layers`：优先用框架和内退墙芯建立画布；只有空间或材料约束明确时切换到 `single-cell relief`。
2. 把窗记录为 `facade_opening_assembly`：必须有开口，顶部 `weather_hood`、底部 `sill_or_display_ledge` 与拉结或支撑均为按用途选择的可选部件。
3. 执行 `opening_frame_integration_check`：新材料和窗构件必须与墙芯、柱或横梁相接；孤立贴片不能仅凭自身形状通过。
4. 把柱划分为可选的 `column_base`、`column_shaft` 和 `column_capital`；细化单元不得抢过柱身，失败时删减或扩大承载比例。
5. 执行 `structural_visual_weight`：较重材料优先承担 frame/support，较轻材料优先承担 infill；点缀色保持有界，不建立固定颜色配方。
6. 空间受限时使用 `constrained_depth_relief`，把部分方块限定在一格进深内；外挂长度、挂点和墙柱交接角色按整体尺度选择。
7. 仅对足够大的墙面启用开间细分，并沿用 `integrated_facade_bay_layering`；小面不为满足模板而强行分区。
8. 编译前检查方块白名单、状态和方向。隐藏照明、锁链、功能方块或植物示例只有在目标版本和便携数据包允许时才能采用。

## 给 Agent 的转化

- `facade_opening_assembly`：以开口为核心，按用途组合遮雨、窗台、展示和承托部件。
- `opening_frame_integration_check`：窗口及其材料必须连接墙芯、柱或梁。
- `column_articulation_zones`：柱基、柱身、柱头是可选语义区，不是强制三段模板。
- `column_ornament_scale_check`：雕花视觉重量不得超过柱身。
- `constrained_depth_relief`：无内退空间时，在一格范围内使用有界部分方块层次。
- `attachment_scale_and_junction`：外挂构件的长度和位置服从建筑尺度与墙柱交接角色。
