## 本集解决的问题

本集说明如何从完整体块中减去一部分空间，使建筑产生凹口、转角玻璃、露台、通道、采光口或错移体块。核心不是“挖得越多越好”，而是先说明减法的可见目的，再按位置、建筑类型和支撑条件选择削减范围；如果削减抹掉原有层次、制造过度碎片或留下无支撑的大跨空洞，就应撤回或缩小。

## 字幕摘要

- 结构减法必须先明确目的，并放在能够改善可见层次的位置；把原有凹凸全部削平会减少有效表面，过多小洞则导致琐碎（约 19–100 秒）。
- 大范围底部或中层挖空更适合能表达高强度结构的现代建筑；古代或仿古建筑不能忽略木、石体系的承托直觉（约 103–172 秒及 371–409 秒）。
- 局部点状削减可形成内凹入口；连续线状削减可形成上部挑出、下部退让的构图，但应补充斜撑或其他可见支撑（约 174–284 秒）。
- 跨越两个立面的转角削减常与玻璃大厅、展厅或办公空间结合；玻璃面可与外墙齐平或进一步内退（约 285–329 秒及 425–467 秒）。
- 削减位置会改变功能：中部开洞可形成穿透空间，中层凹口可形成阳台，顶部削减可形成平台并增加采光（约 330–538 秒）。
- 整层底部退让可形成柱列支撑的停车或通行空间；连续空洞还可引入天窗和天光，但不能省略承托上部体量的构件（约 559–650 秒）。
- 整块削减可以采用阶梯或斜切，形成露天花园等空间；把减去的体块平移、旋转或错开，是把加法与减法结合成错层构图（约 654–785 秒）。

## 可执行流程

1. 在完整且已通过体块检查的 `source_mass` 上声明 `subtraction_intent`，例如 entrance_recess、corner_glazing、terrace、passage、lightwell 或 mass_shift；没有用途的空洞不进入蓝图。
2. 用 `void_region` 表示相对坐标削减区，并记录其 `void_position`：base、middle、corner、top 或 full_layer。最终编译仍只输出相对坐标，不依赖编辑模组。
3. 执行 `articulation_preservation_check`：减法后主要凹凸、轮廓和体块层次不能比原方案更少；若只是把有效表面削平，则回退检查点。
4. 执行 `fragmentation_check`：合并没有独立功能的邻近小洞，避免把连续体块切成无主次的碎片。
5. 对 base、middle 或 full_layer 大空洞执行 `void_support_check`，要求上部荷载在视觉上连接到柱、墙、斜撑或其他既有支撑路径；建筑风格和材料角色不支持大跨时缩小空洞。
6. 检查空洞产生的用途是否成立，包括入口遮蔽、通行净空、采光、阳台或平台的可达性，以及玻璃面与外墙的进退关系。
7. 若使用 `cut_translate_recompose`，先保存被减体块的相对边界，再进行平移、离散旋转或错移；重新检查连接、碰撞、支撑和多视角轮廓。

## 给 Agent 的转化

- `subtraction_intent`：任何减法必须绑定可见构图或空间用途，不能以随机挖洞代替设计。
- `void_region` / `void_position`：用相对选区和 base、middle、corner、top、full_layer 位置描述削减。
- `articulation_preservation_check`：拒绝抹平原有有效凹凸、减少主体层次的削减。
- `fragmentation_check`：限制无角色的小洞重复，保留连续主体和明确留白。
- `void_support_check`：大空洞上方的体量必须连接到可读的支撑路径，并服从建筑类型与材料角色。
- `cut_translate_recompose`：将减去的块作为同源模块平移或旋转，以形成有连接的错层体块。
