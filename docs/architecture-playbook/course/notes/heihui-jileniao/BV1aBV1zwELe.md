## 本集解决的问题

本集不是新的建筑风格教程，而是把大型建造拆成可以撤销、复用和组合的操作。核心思想是：先选择有边界的区域，再围绕相对锚点复制、移动、旋转、镜像或重复；复杂地形先做粗形，再平滑、加噪声或粗糙化。工具名称属于作者的工作环境，Agent 应吸收其中的操作语言，而不要求玩家安装这些模组。

## 字幕摘要

- 施工时优先使用舒适、性能影响较小的光影；写实或梦幻光影更适合最终观赏，而不是持续施工（约 81–115 秒）。
- WorldEdit 的多数编辑都从两点选区开始；错误操作应使用 undo/redo 回退或重做（约 391–478 秒）。
- copy 保存玩家与选区的相对位置；paste 按该相对关系落位。忽略空气的粘贴适合把模块嵌入已有结构（约 484–547 秒）。
- 已复制的模块可以 rotate 或 flip，再进行粘贴；schematic 用于跨存档复用结构（约 599–695 秒）。
- sphere、smooth、line、stack 和 move 分别对应体量刷制、地形平滑、精确拉线、方向重复和整体位移（约 697–849 秒）。
- Axiom 提供快速替换、强制放置、方块状态调整、远距放置、对称、拉伸、延展、堆叠、克隆、旋转与翻转等交互式编辑（约 949–1345 秒）。
- 噪声绘制适合生成非均匀纹理；形状、钢笔与曲线工具适合圆形和曲线；高度、斜坡、平滑与粗糙工具构成地形从粗形到表面处理的流程（约 1396–1599 秒）。

## 转成可执行建筑语言

| 作者操作 | Agent 建筑语言 | 便携实现含义 |
| --- | --- | --- |
| 两点选区 | `selection_region` | 对一个有边界的相对坐标集合操作 |
| copy 的站位关系 | `relative_anchor` | 模块坐标以锚点归一化，不保存世界绝对坐标 |
| copy / paste | `module_instance` | 定义一次模块，在多个相对位置实例化 |
| paste 忽略空气 | `placement_mask: non_air` | 组合模块时不清除目标处已有结构 |
| rotate / flip | `module_transform` | 对模块应用离散旋转或镜像后再编译方块 |
| stack | `linear_repeat` | 沿给定方向和步长重复模块 |
| 对称工具 | `symmetry_repeat` | 围绕平面或中心复制同一母题 |
| move / 拉伸 / 延展 | `region_transform` | 位移或改变已选区域，而非逐块重新描述 |
| noise 绘制 | `material_noise_mask` | 在限定区域内按确定性种子混合材料 |
| 高度 / 斜坡 / smooth / roughen | `terrain_pass` | 依次执行粗塑形、衔接、平滑与表面扰动 |
| undo / redo | `construction_checkpoint` | 每个批量变换前保存可回退检查点 |

## 给构建 Agent 的流程补充

1. 把重复构件先定义为一个带 `relative_anchor` 的模块，不逐份生成独立方块表。
2. 在任何批量修改前保存 `construction_checkpoint`。
3. 通过 `module_transform` 生成旋转或镜像变体；通过 `linear_repeat` 或 `symmetry_repeat` 放置实例。
4. 模块嵌入已有建筑时使用 `placement_mask: non_air`，避免空气覆盖既有方块。
5. 地形先用大尺度 `terrain_pass` 建立高度和坡面，再执行 smooth；最后才加受限的 noise 或 roughen。
6. 所有模组式操作都在生成阶段展开为确定性的相对坐标方块操作。最终产品仍是便携 `architect_datapack/`，玩家不需要安装 WorldEdit、Axiom 或其他建造模组。
