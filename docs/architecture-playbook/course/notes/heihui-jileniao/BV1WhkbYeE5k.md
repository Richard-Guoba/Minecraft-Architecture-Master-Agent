## 本集解决的问题

屋顶不能只被当成封顶算法。它同时决定建筑轮廓、材质分区、尺度感和体块之间的连接。本集最稳定的三条线索是：明确边界、让坡度适配体量、打断过大的连续平面。

## 可执行流程

1. 从已确认的框架跨度生成屋顶核心面。
2. 选择一格一升、两格一升或分段变化的坡度节奏。
3. 用与屋面主体不同的材质或明度建立连续包边。
4. 检查屋面是否与墙体在颜色和轮廓上粘成一块。
5. 检查主视角中是否出现过大、过平、无转折的连续坡面。
6. 必要时加入次级屋顶、转折、曲线或与其他体块相交的屋面。
