# 3.4 门：门框连续、入口过渡与可见纵深

## 本集解决的问题

本集把门从单个方块扩展为入口系统：门板、门框、门头、门槛、台阶、雨棚和内部门厅按尺度与用途组合。课程反复允许省略实体门板，尤其在大型门洞或小比例无法准确表达时；入口的价值来自通行、层级、遮雨和内外纵深，而不是把每个示例花纹固化为模板。

## 字幕摘要

- 同系列门与活板门可形成连续门板；纹理或分段不连续时会产生割裂。楼梯、玻璃板和部分方块可用于缩小门板与门框之间的锯齿和空隙（约 8–37 秒及 85–175 秒）。
- 地基抬高时，入口需要门槛或多级台阶连接地面；灯笼和花盆属于可选从属装饰（约 183–256 秒）。
- 小比例可用的细节有限；大型入口可以划分层次，也可以只保留可通行门洞与门框而省略实体门板（约 258–297 秒）。
- 玻璃门依赖材料的连接状态；材质包示例和红石双控电路不是通用入口规则（约 40–79 秒及 298–345 秒）。
- 当具体门扇在小比例难以准确表达时，课程再次建议使用空门洞。大型透视门通过从外到内逐层缩小建立层级，这一方法可缩小后用于普通入口（约 399–463 秒）。
- 门口附属构件、岗亭或装饰只有在服务入口角色时才有意义；门厅提供等候和挡雨空间，顶部中央抬高、两侧导水，避免雨水直接落在入口（约 565–630 秒）。
- 大拱门可把“外圈较大、内圈较小”的嵌套方法缩小为日常门厅；城门机械运动和模组能力只是演示，不进入标准数据包（约 631–721 秒）。
- 大型入口可以与内部前台、门厅或第二道门联动；从外部看到内部焦点会增加纵深。大型敞口比小门更依赖内部景观（约 749–843 秒）。

## 可执行流程

1. 建立 `entry_opening` 和 `entry_frame`，再按纹理连续性、连接状态和厚度选择门板或部分构件；门头细节只修复有界接缝。
2. 执行 `entry_scale_check`：小门不堆叠超出比例的雕花；大型门洞或无法精确表达门扇的小比例立面允许 `door_panel: omitted`，但必须保持可通行开口和清晰门框。
3. 大型或纪念性门洞可使用 `nested_portal_depth`，从外圈到内圈有序收缩；不复制字幕中的随机内部花纹。
4. 地基高于入口地面时建立 `threshold_or_stair_transition`，连接玩家通行路线；可选装饰不得占据净空。
5. 有等候或天气需求时加入受支撑的 `entry_canopy` 或门厅，让雨水向开口两侧导流；不从字幕推断现实防水工程参数。
6. 大型敞口使用 `layered_entry_sequence`：外框、门厅或前台、内部门槛形成连续纵深，并从外部检查内部焦点与通行。
7. 编译时只使用目标版本与白名单允许的门、方块状态和相对坐标；红石、机械动力、材质包或模组示例不成为默认依赖。

## 给 Agent 的转化

- `door_frame_material_continuity`：按纹理和连接状态协调门板、门框及门头。
- `entry_scale_check` / `door_panel: omitted`：入口角色和尺度优先于强制实体门板。
- `nested_portal_depth`：用有序缩进建立门洞层级。
- `threshold_or_stair_transition`：连接抬高入口与地面通行。
- `weather_sheltered_entry`：门厅或雨棚承担等候、遮雨和导流角色。
- `layered_entry_sequence`：把外框、内部焦点和第二道门组织为可见纵深。
