## 本集解决的问题

本集处理大型空白墙面：不靠堆满互不相关的技巧，而是按材质连接性分配角色，从有限小单元建立重复语法，增加真实体量获得进深，并通过主分区、角色分配、次分区和反复比例修正让墙面逐步生长。

## 字幕摘要

- 材料可按连续表面、显著特征、平滑致密和带边框等视觉类型理解。连续材料适合大面，较致密或深重材料适合柱和承托；显著纹理在小尺度影响更强（约 47–335 秒）。
- 大墙面先学习少量线条、柱和凹槽单元，再以有规律的间隔排列组合；一百格墙面不应使用一百种独立元素（约 374–512 秒）。
- 单格浮雕仍只有有限深度；需要更强层次时必须增加墙面体量，用深层平面及阴影产生同材质内的明暗分离（约 512–578 秒）。
- 把学到的所有技巧塞进同一小墙会失去逻辑；斗拱、斜撑、彩窗或植物若没有角色，不能因“技巧丰富”而保留（约 583–663 秒）。
- 实例从空墙开始，先建立边框和主分区、指定门洞与实心区域，再调整横纵次分区。过多宽度变化会破坏规律，需要反复修改对齐与比例（约 664–779 秒）。
- 后续用部分方块细分、重复已有元素、删除抢眼的平滑条并修正门洞比例；大型墙面还需足够采光和预先规划的实空层级（约 779–978 秒）。
- 同一平面不足时增加从属平面；边缘用宽度收束表达结束。最终原则是结构有内在逻辑并逐步发展，而非在画布上无序添加（约 990–1,046 秒）。

## 可执行流程

1. 建立 `facade_material_profile`，按连接性、视觉密度、边框和方向纹理分配 surface、support 与 accent。
2. 定义有限 `facade_pattern_vocabulary`，用共享对齐线组合重复节奏；拒绝每个开间一个全新元素。
3. 浅浮雕不足时执行 `facade_depth_expansion`，增加有边界的从属平面；不以提高表面噪声代替体量。
4. 从 `primary_partition` 开始分配门洞、实心和通透区域，再建立对齐的次分区。
5. 迭代检查宽高规律、视觉焦点、采光和实空层级；删除非预期强对比条，修正比例后才加入细节。
6. 新构件必须复用既有语汇或有明确角色；无承托、无开口或无收束作用的技巧组合予以删除。
