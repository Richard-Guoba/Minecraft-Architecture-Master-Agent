## 公开产物

- 六篇单集原创讲义，分别覆盖体块、主次、屋顶、墙面、中世纪结构和完整案例。
- 21 条 `PlaybookRuleCandidate`，每条至少引用一个公开 Evidence ID。
- 一条条件冲突：小尺度窗式重复用于统一，完整墙间重复需要被打破。
- 七个未知项，覆盖比例阈值、空白面阈值、重复上限、坡度映射、跨尺度泛化、美学评价器和跨作者有效性。
- 一个公开 Evidence 索引，记录六个私有证据包的哈希和 21 个 Evidence ID，不包含原始媒体或逐字稿。

## 证据链

每集私有 EvidencePack 同时校验以下血缘：

`课程元数据指纹 → 媒体 SHA-256 → ASR v2 片段索引 → 事件帧索引 → 术语复核 → EvidenceNote`

公开候选规则再通过 Evidence ID 连接到 EvidencePack 摘要。公开加载器验证六集覆盖、Evidence ID 覆盖、候选规则合同、冲突双向引用、未知项和讲义中的包哈希。

## 已解决的工程问题

1. 私有 Python 原生依赖要求 CPython 3.12；处理命令现已固定 ABI，避免 Anaconda 3.11 错载 NumPy 扩展。
2. Python 与 JavaScript 对 `-0.0`、整数浮点和科学计数法的 JSON 表达不同；ASR v2 哈希只覆盖跨语言稳定的时间戳、文本和词级血缘。
3. 长视频下载会话在后台不轮询时被回收；通过持续轮询完成 234,780,655 字节媒体的流式校验。
4. 视觉证据不由固定间隔抽帧产生；每帧均关联经复核的字幕教学事件，并由人工查看 contact sheet 后升级为 `visually-reviewed`。

## 边界与风险

- 这些规则描述一个作者的教学流派，不等同于普遍美学规律或现实建筑史结论。
- ASR 是草稿。具体方块名称不可靠时，术语被保留为 unresolved，未生成材料参数。
- 21 条规则目前没有定量阈值；参数数组有意保持为空，不能伪造精度。
- EvidenceNote 和候选规则均为 `draft`；只有后续生成实验和人工偏好评测能推动成熟度升级。
- P2 没有修改生产建造器，因而不存在“看过课程就自动会建”的虚假完成声明。

## P3 建议入口

P3 不应继续无边界地看视频，而应先把这 21 条规则压缩成可执行秘籍 v0.1：

1. 定义 `brief → viewpoint → massing → hierarchy → structure → roof → facade → palette → vegetation → scene → critique → repair` 中间表示。
2. 为每条候选规则标注触发条件、读取字段、写入字段、检查器和修复动作。
3. 生成三个中世纪民居候选，使用固定多视角渲染和分层 rubric。
4. 至少完成一次“发现缺陷—定位设计层—定向返工”，并与当前生成器盲选比较。

只有这个闭环成立后，再扩大到其余 44 集，才能让新增资料直接填补明确的未知参数，而不是继续堆积笔记。
