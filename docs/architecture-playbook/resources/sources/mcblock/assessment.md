# MCBlock 建筑库评估

## 定位

[MCBlock 建筑库](https://mcblock.top/buildings)是多作者案例目录，不是本项目的学校、课程或规则来源。公开页面把三维预览、逐层学习、数量信息与导出格式作为站点能力介绍；这些声明不等于批量下载、模型训练或再发布许可。

## 探针覆盖与局限

五个只读探针覆盖不同难度、风格和体量：

- [茶坊](https://mcblock.top/buildings/c8db481c-e86e-47ae-976d-2a870ab2855b)与[玉桂狗咖啡厅](https://mcblock.top/buildings/7583ff98-a659-487c-b71a-731075f99b0c)保留列表卡片中的短事实和明确作者字段。
- [维多利亚庄园](https://mcblock.top/buildings/6e5b406e-151d-492c-91c4-e8b22d1920b0)记录详情页直接可见的标题、难度、尺寸、标签与步骤摘要；“JPCore 的更多投影”不作为作者证据。
- [现代办公楼·四](https://mcblock.top/buildings/06941222-9fae-4045-882a-f82b4feb71f7)与[樱花女巫小屋](https://mcblock.top/buildings/5f3aff4d-3a47-4fb7-8f08-5da73250e66d)只保留列表卡片短事实，作者保持未知。

多数详情依赖 JavaScript，探针没有保存网页正文、HTML、图片、材料清单、逐层数据、模型或下载文件，也没有记录相互矛盾的站点总量。

## 九维判断

| 维度 | 评分 | 判断 |
|---|---:|---|
| 设计原则 | 1 | 探针主要展示案例和操作入口，设计理由说明有限。 |
| 施工顺序 | 4 | 站点明确以三维逐层学习为核心，但多数样本的详情数据尚未稳定直读。 |
| 参考案例 | 4 | 五个样本覆盖风格、难度和体量差异，案例参考价值高。 |
| 材料 | 3 | 站点声明提供方块数量或材料信息，详情可见性仍不一致。 |
| 生存约束 | unknown | 现有探针不足以确认生存模式成本或施工约束。 |
| 评价 | 2 | 难度、尺寸和方块量可辅助比较，但未观察到系统设计评价。 |
| 来源追溯 | 2 | 部分案例有作者字段，另一些作者未知且页面字段不稳定。 |
| 访问稳定性 | 2 | 列表可见但详情依赖动态渲染，五个页面的可读程度不一致。 |
| 权利清晰度 | unknown | 免费和可导出声明不能证明训练、批量下载或再发布权利。 |

## 技术与来源风险

详情页动态渲染造成字段可见性不一致，登录要求、自动化访问条件、接口、导出操作和速率限制均未完成审查。案例修订与内容指纹未知，作者字段也不完整。公开可读仅支持本次只读观察，不能扩大解释为下载、训练或再分发授权。

## AI 建议

建议 `recommend-defer`。在项目所有者另行审查访问方式与权利边界前，不把 MCBlock 内容接入课程、规则、训练或批量处理流程。

## 获批后的适配器边界

若以后获批，只设计站点专用的只读元数据/逐层查看器适配器；速率、登录、权利与导出边界分别复核。适配器只返回经批准的最小元数据或查看入口，不能直接向课程、规则或训练供给内容。
